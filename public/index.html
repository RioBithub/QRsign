Setelah QR dimasukkan ke slide terakhir / footer dokumen, simpan dokumen final lalu upload di sini. Setelah FINAL, file tidak dapat diganti dari UI ini.

Cara Pakai

  1. Buat record → sistem memberi Document ID, link verifikasi, dan QR.
  2. Masukkan QR ke PPT/PDF/dokumen, misalnya pada slide terakhir bertuliskan “Verify authenticity”.
  3. Upload file final → server menghitung SHA-256 dan mengunci record.
  4. Saat QR discan, pengguna dapat download file resmi dan menguji file yang mereka punya. Hash sama = file identik bit-per-bit.
